Java——Optional类的使用

发表于2022-11-25|Java
|总字数:3.7k|阅读时长:17分钟|浏览量:

Optional 是一个容器对象：要么包含一个非 null 的值，要么为空（empty）。有值时 isPresent() 返回 true、get() 返回该值；为空时 isPresent() 返回 false。
它不保存 null——容器内部的 null 只表示「没有值」（Optional.empty() 与 ofNullable(null) 拿到的都是它）；Optional 变量本身也永远不该是 null，这是官方 API Note 明确要求的。
Optional 把「这个值可能为空」写进类型，让调用方必须显式处理；它并不消除空指针异常。

flatMap()转换值

flatMap() 与 map() 的差别在于映射结果还要不要再包一层：map() 会把映射结果按 ofNullable() 包起来，所以映射函数本身返回 Optional 时会得到嵌套的 Optional<Optional<T>>；flatMap() 要求映射函数直接返回 Optional，也不会再包装，嵌套因此被摊平。边界也别记错：map() 的映射函数返回 null 只会得到空 Optional，flatMap() 的映射函数返回 null 直接抛 NullPointerException（上面示例里的 Person::getName 返回的就是 Optional<String>）。
